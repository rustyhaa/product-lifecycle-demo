# 상품 한 장 데모

> **둘러보기(10장면, 약 3분)**: [https://rustyhaa.github.io/product-lifecycle-demo/?tour=0#/](https://rustyhaa.github.io/product-lifecycle-demo/?tour=0#/) — 가상 상품 하나를 품의 추적 → 상품 한 장 → 처분 화면까지 따라가며, 장면마다 무엇을 왜 만들었는지 설명합니다. 어느 화면에서든 맨 위 띠의 "둘러보기 ▶"로 시작할 수 있고, 키보드 ←/→/Esc로도 움직입니다.

상품 하나의 전체 이력(상태·행사·처분, 입고, 판매, 센터·점포 재고, 체화)을 같은 시간축에 놓은 화면과, 그 위 단계인 요약 화면의 목업입니다.

**모든 숫자와 상품은 가상입니다.** 실제 회사·상품·수치가 아닙니다.

- `index.html`: 요약 한 장 ↔ 상품 한 장 (해시 이동, 밝은/어두운 판)
- `data.json`: 화면이 읽는 유일한 데이터 (`data.js`는 파일로 바로 열 때 쓰는 같은 내용 사본)

상품 8개는 판매 수명 유형 6가지(① 정점이 초반·이후 하락, ② 완만 상승·유지, ③ 계절성, ④ 하락 후 재상승, ⑤ 실적이 짧은 신상품, ⑥ 행사 급등)마다 1~2개씩 만든 가상 상품입니다. [품의 추적](https://rustyhaa.github.io/import-lifecycle-demo/)·[처분 화면](https://rustyhaa.github.io/disp-lifecycle-site/)과 같은 상품이라, 각 화면의 링크가 같은 상품으로 이어집니다.

GitHub Pages로 열거나, 내려받아 `index.html`을 더블클릭하면 됩니다.

## 세 화면 공통 위쪽 띠
`lifebar.js`: 세 화면(품의 추적·상품 한 장·처분) 맨 위에 같은 띠를 둡니다. 상품을 고르면 그 화면이 같은 상품으로 바뀌고, 띠의 단계를 누르면 같은 탭에서 다른 화면의 같은 상품으로 갑니다. 상품 목록은 공용 가상 데이터 생성기가 만듭니다.

상품 한 장의 판매 줄에는 같은 유형 가상 상품 40개로 만든 "유형 정상 범위"(25~75%, 점선 = 중앙값)가 깔리고, "유형대로 발주했다면" 단추를 누르면 정상 모양만큼만 채웠을 때의 재고·체화가 청록 점선으로 겹칩니다.
